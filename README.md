# Production RAG Starter

A production-oriented reference implementation for building
Retrieval-Augmented Generation (RAG) applications.

Designed to demonstrate the engineering patterns required to move
from a basic "chat with your documents" prototype to a reliable
production system.

## Features

- Document ingestion and chunking
- Vector and hybrid retrieval
- Reranking
- Grounded LLM responses with citations
- FastAPI REST API
- Streaming responses
- Structured outputs
- Retrieval and answer evaluation
- Observability and tracing
- Dockerized local development
- Infrastructure as Code
- CI/CD
